# PiBrowse 代理服务商推广位

用户要求将上游 Fury 的代理商推广位换成自己的，并委托筛选几家可申请的供应商。

本轮采用中央配置管理 Webshare、Decodo、Proxy-Seller、蜘蛛IP 四家。未取得自有推广链接的服务商使用官网入口；已取得账号分配或用户提供的自有公开推广链接时，使用该完整地址并披露推广关系。名称和产品概述依据官方来源，不展示未经确认的用户折扣。原 Fury 专属 refid、优惠码和35%折扣标语退出当前展示路径。

每家保留可选 promotion 配置，填入账号已分配或用户明确指定的自有公开推广链接，优惠码仅在实际取得时配置。只有 approved=true 且 URL 为不含用户名密码的 HTTPS 地址，才使用推广链接和对应优惠码、合作标识；否则回退官网，隐藏所有优惠码。返佣比例仅存在运营申请说明，不作为用户折扣。

目录保持本地，无远程推荐配置或自动注册、采购、商家消息；不主动发送环境和代理数据。用户点击时通过现有 api.openUrl 打开链接。开户协议、KYC、付款与身份资料由用户处理；本轮获用户授权的 Impact 复核工单单独记录在运营文档。

申请资料以 PiBrowse、https://pibrowse.dev/、https://github.com/aronhy/pibrowse 为产品背景；不虚报流量、用户量或合作关系。申请前需指定注册邮箱，协议接受/身份核验由用户完成。新申请中如实说明桌面客户端渠道并遵守对应规则；没有明确要求时，不将已激活联盟的普通推荐链接使用自行扩张为必须重新审批。

复用现有主题、按钮、复制和外部浏览器行为；提供中英俄文字和英文回退。验证配置门控/URL/优惠码行为、完整前端测试与构建，以及隔离客户端代理页截图。发行包与真实商家账号开通状态单独报告。
