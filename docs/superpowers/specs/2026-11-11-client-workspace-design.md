# 客户端快速创建与环境列表

用户已选择本轮实施：快速创建（名称、代理、启动网址、高级展开、草稿保护）和列表效率（最近使用、异常筛选、排序、置顶、保存筛选、自定义列）。

采用现有 React/Tauri 编辑器与虚拟列表增量改造。相比新增独立编辑器，此方式复用保存、代理解析、设备选择、团队权限与指纹验证，避免两套配置行为漂移。相比重做整个客户端，范围保持在两个已选功能。

新建默认快速模式，展示名称、代理配置和启动网址；高级模式显示现有页签，切换保留全部输入，编辑已有环境默认高级模式。沿用现有同系统加权设备选择与代理安全约束。常规摘要简化，完整参数可展开。关闭、遮罩和 Escape 均保护已改输入，提供继续编辑、保留草稿和丢弃；草稿仅在当前 App 生命周期的内存保存，按目标项目/来源区分，不把代理密码、WireGuard 配置、轮换密钥写入浏览器存储。成功保存清除草稿。切换模式不改设备或代理值。

列表保留现有搜索、标签、阶段、运行中筛选，新增全部/最近7天/需处理/置顶快捷视图。需处理基于已有一致性校验、保存失败和 limited/banned 阶段，不把正常被同事占用当异常，不声称检测了网站封号。支持默认/最近打开/名称正序/名称倒序/异常优先排序，置顶在匹配结果内优先。名称、选择和操作列始终可见，项目、代理、状态、最近打开列可切换。保存视图包含当前筛选、排序和列，支持命名、切换、删除；不隐式切换项目。列表偏好按服务端地址与账户隔离，本地模式独立保存；损坏或不可用的 localStorage 不阻断页面。

列表刷新后保留筛选/置顶，筛选变化后选择项只影响当前可见结果，全选以集合包含关系判断，避免误选隐藏环境。已有权限、行内启动/保存状态和虚拟列表保持可用；更改筛选/排序时修正虚拟滚动范围。使用现有主题变量，提供中文、英文、俄文及英文回退。

不涉及内核指纹、后台服务、云端数据结构、收费、部署或其他稳定性修复。验证采用纯逻辑行为测试、TypeScript/Vite 构建、隔离浏览器预览交互与截图；真实安装包和代理网络验收单独说明。
