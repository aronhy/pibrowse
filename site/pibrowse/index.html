Download for Apple Silicon.

First launch on macOS · 首次打开需手动授权

This preview has no Apple Developer ID signature or Apple notarization. If macOS says Apple cannot verify PiBrowse and you trust this download, follow these steps to approve the app manually.

  1. Move PiBrowse.app to Applications, then try to open it.
  2. Open System Settings → Privacy & Security, find the PiBrowse notice and click Open Anyway.
  3. Confirm Open when prompted. macOS may ask you to authenticate.

中文：先将 PiBrowse.app 拖入「应用程序」并尝试打开；如果被拦截，确认下载来源可信后，进入系统设置 → 隐私与安全性 → 找到 PiBrowse →「仍要打开」，再按系统提示确认。当前预览版需要你自行完成这一步授权。

1 · Desktop application

PiBrowse for macOS

The desktop workspace for profiles, proxies and local or self-hosted use. For Apple Silicon Macs (arm64).

Download desktop (.dmg) ↓

2 · Browser core

Chromium 157.0.8103.39

The PiBrowse browser engine. Install it with the desktop app’s Download the browser button, or import this archive manually.

Download core (.tar.xz) ↓
  1. Open the desktop download and move PiBrowse.app to Applications.
  2. Open PiBrowse and choose Download the browser to install the matching core.
  3. Create a local profile, or connect to your own team server.

Preview status: the macOS app and core are ad-hoc signed, without an Apple Developer ID or Apple notarization. macOS may block the first launch; follow the manual approval steps above. Automatic updates are not configured. This release includes no Windows or Intel Mac binary.
